# Local fonts

The site self-hosts the Latin WOFF2 subsets used by the original design:

- DM Sans (300–600)
- DM Mono (300, 400, 500)
- Playfair Display (500, 600, and 500 italic)

The files were retrieved from Google Fonts and are distributed under the SIL Open Font License. Source specimen pages:

- https://fonts.google.com/specimen/DM+Sans
- https://fonts.google.com/specimen/DM+Mono
- https://fonts.google.com/specimen/Playfair+Display
